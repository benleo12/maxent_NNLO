# Frozen W predictivity study: independent result

Both charges select R+H+S from training alone. The additional information is recoil–decay structure: the hard-window spin functions H and continuous recoil-suppressed functions S. The selected functions vanish at Born level, so the inclusive NNLO input supplies them at NLO. They do not establish resummed recoil accuracy. R minus the old blended anchor remains a separate prescription comparison.

The clearest physics result is the old30 acceptance decomposition. In percentage points, W+ R minus the independent reference is +0.073±0.087 from projected populations and −0.576±0.063 from recoil migration. The selected result is +0.086±0.086 and −0.156±0.057. Its paired total change is +0.433±0.034, of which +0.420±0.034 is migration. W− changes from −0.013±0.097 projected plus +0.542±0.057 migration to −0.013±0.098 plus −0.145±0.053; its paired total change −0.687±0.029 is essentially all migration. These terms use the same originally selected events and exact I=I0+(I−I0), with full common covariance. Migration combines transverse boost and azimuth; it is not an isolated shower error.
