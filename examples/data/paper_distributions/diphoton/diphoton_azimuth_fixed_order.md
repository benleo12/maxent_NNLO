# Continuum diphoton azimuthal separation against fixed order

[Azimuthal predictions and ratios](diphoton_azimuth_fixed_order.csv) give the distributions used in the fixed-order comparison. The two reweightings and the NNLOJET calculation use the ATLAS 8 TeV fiducial photon selection and smooth-cone isolation, with the profiles specified in the paper. The normalized reference uses the full diphoton NNLO cross section for each of its seven scale choices. For azimuthal separation below π the first nonzero contribution requires a recoiling parton, making the NNLO calculation NLO accurate there. The bin containing exactly back-to-back photons also receives the Born contribution. Its fixed-order value is omitted from this differential comparison.

- For `jet_me`, the prediction and reference use the original fixed-order bin edges. Adjacent bins below π/2 are combined for statistical precision. The scale and numerical errors respect these combinations.
- For `shower_only`, the proposed angular bins are exact unions of the measured bins in the archived full event sample. Less than 10% of any bin yield comes from one event. The first bin covers 0 to 1.75 radians.
- These wider shower-only bins cut through a few of the finer reference bins. At each affected boundary the reference rises with the azimuthal separation. Assuming it also rises within those boundary bins, their integrals and the two adjacent average densities bound the partial contribution. The central reference is the midpoint of this interval. Its half-width is at most 0.63% for the first five bins and 1.94% for the last bin at any scale. Merging pairs of native fixed-order bins and then testing the bound at the original internal boundaries gave 42 successful checks over the seven scale choices.

`prediction`, `reference` and the scale columns are normalized densities in inverse radians. Each scale column uses its corresponding fiducial cross section. `event_error` is the finite-event error at fixed weights, including the correlation with the full fiducial normalization. `reference_bin_low` and `reference_bin_high` bound the central reference when a bin must be split. The data comparison uses the [native ATLAS bins](atlas_recoil_azimuth.md).
